An entry for the [make.fun](https://make.fun) competition
"One Word for the Boss"
([competition page](https://make.fun/competitions/u-swift-badger-44-one-word-for-the-boss-6b48c735)).

## The entry

`main.py` (Python 3.13, stdlib only, no network) scores a shortlist of
candidate words against the judge's five criteria — single word, funny on
its own, rings true, fresh, travels — and writes the winner, one word, to
`/output/entry.txt`.

The winning word is **Rescheduler**: the boss who moves every meeting,
again and again. A job-title word, instantly true, fresh (not the first
word anyone reaches for), and it works in a kitchen, a warehouse, or an
office.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
